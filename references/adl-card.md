# A/D Line（累积/派发线 – Accumulation/Distribution Line）

## 计算公式
MFM = [ (收盘价–最低价) – (最高价–收盘价) ] / (最高价–最低价)  
MFV = MFM × 成交量  
A/D = 前一日 A/D + MFV  
涨跌停时 MFM = 收盘价/昨收 – 1。

## 核心逻辑
收盘价越接近最高价 → MFM 越接近 +1 → 资金积累（买入）  
收盘价越接近最低价 → MFM 越接近 -1 → 资金派发（卖出）

## 实战看点
- **顶背离**：价格新高（>前高点×1.02），但 A/D 未新高（≤前高点×1.01） → 主力派发，卖出信号  
- **底背离**：价格新低（<前低点×0.98），但 A/D 未新低（≥前低点×0.99） → 主力吸筹，买入信号  
- **同步上升**：股价与 A/D 同步新高 → 真突破，资金质量好  
- **趋势确认**：近 20 日 A/D 整体抬升 + 价格上升 → 中期健康上涨  
- **强度对比**：A/D 20日变化率 / 价格20日变化率 > 1.5 → 资金积极流入  

## 与 OBV 差异
OBV 看方向（粗），A/D 看质量（细）。

## 局限性
跳空缺口失真，横盘行情噪音多。
